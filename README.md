# EduSkills Academy – Cloud Tuition Management

A lightweight Vercel-ready web app backed by Supabase.

## Included
- Permanent student database and unique admission numbers (`EDA-YYYY-001`)
- Parent/guardian contact details
- Monthly fee ledger; multiple partial payments per month
- Unique receipt numbers, printable receipts, WhatsApp text sharing and JPG receipt sharing
- Attendance register
- Printable student ID cards
- WhatsApp fee-reminder link (opens WhatsApp with a prefilled message; admin sends it)
- Search, reports and CSV exports

## Setup (required before first use)

### 1. Create a Supabase project
1. Visit https://supabase.com/dashboard and create/sign in to an account.
2. Create a new project, e.g. `eduskills-academy`. Save the database password securely.
3. In the project, open **SQL Editor → New query**.
4. Open `supabase-schema.sql`, copy all its contents, paste into SQL Editor and click **Run**.
5. Go to **Authentication → Users → Add user**. Create your admin email and password. Confirm the user if prompted.
6. Open **Project Settings → API** (or **Connect**) and copy:
   - Project URL
   - anon/public key or publishable key (`sb_publishable_...`)
   Never copy/use `service_role` or secret keys in this website.

### 2. Deploy to Vercel
1. Visit https://vercel.com/new and sign in.
2. Choose **Deploy a project** / drag-and-drop (Vercel Drop).
3. Upload the extracted project folder containing `index.html`.
4. No build command is required. The site is static.
5. Open the deployed `.vercel.app` address.

### 3. Connect the app
1. Open your deployed site.
2. Paste the Supabase Project URL and anon/public key.
3. Sign in using the admin user created in Supabase.

## Important security notes
- The browser stores only the Supabase URL and public/anon key. This key is designed to be public; RLS policies protect the data.
- Do not put a `service_role` or secret key in this app, Vercel frontend variables, screenshots, or chats.
- The supplied SQL policies allow any authenticated user in this Supabase project to manage all rows. For a single-owner setup, create only your own auth user and do not enable public signups. If adding staff later, use role-based policies before creating staff accounts.
- For stronger multi-staff security, restrict policies by an owner/admin table and roles before inviting staff.
- Student and parent details are personal data. Use a strong unique password, restrict account access, and maintain backups.

## Data and backups
Data persists in Supabase independently of Vercel/browser/device. CSV exports are available in Reports and Settings. Also configure/retain Supabase database backups from the Supabase dashboard; CSV is not a full database backup.

## Feature notes
- Admission number is generated by a database trigger and remains attached to the student.
- Payments are append-only from this app; partial payments are separate transactions.
- Fee balance = monthly fee minus sum of payments for that student and fee month. Overpayments are recorded; displayed balance is floored at zero.
- WhatsApp reminder opens `wa.me` with a prefilled message. It does not send automatically.
- Attendance is recorded per student per date; editing an existing day's register uses an upsert.

## Suggested first test
Create one test student, record two partial payments for the same fee month, confirm the ledger balance, print a receipt, mark attendance, and export CSV. Delete test data only after verifying the workflow.
